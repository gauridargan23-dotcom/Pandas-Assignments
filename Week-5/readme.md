Spark Data Processing Assignment

Overview

This project is part of the Celebal Technologies Internship (Week-5). It demonstrates the fundamentals of Apache Spark using PySpark DataFrames, including data cleaning, filtering, aggregation, schema modification, and building a complete data processing pipeline.

Technologies Used
- Python 3
- Apache Spark (PySpark)
- VS Code
- CSV Dataset (Sample - Superstore)

Project Objectives
- Understand Spark fundamentals and DataFrame concepts.
- Demonstrate DataFrame immutability.
- Remove duplicate records.
- Handle null and empty values.
- Apply filtering conditions on the dataset.
- Perform aggregation using Spark functions.
- Group data using groupBy().
- Understand wide transformations and shuffle operations.
- Modify DataFrame schema by renaming and casting columns.
- Build a complete data processing pipeline.

Features Implemented
- Load CSV dataset using Spark.
- Display schema and sample records.
- Count rows and columns.
- Remove duplicate records.
- Identify and handle null values.
- Filter data by Category and Region.
- Calculate:
  - Total Orders
  - Total Profit
  - Average Profit
  - Maximum Profit
  - Minimum Profit
- Group data by Region and calculate average profit.
- Apply conditions on aggregated data.
- Demonstrate wide transformation using groupBy().
- Rename DataFrame columns.
- Replace empty values.
- Build a complete Data Processing Pipeline.

 Output
The program displays:
- Dataset schema
- Null value statistics
- Duplicate record count
- Aggregation results
- GroupBy analysis
- Final pipeline output with Region-wise Total Orders and Average Profit

 Learning Outcomes
- Apache Spark Fundamentals
- Spark DataFrames
- Data Cleaning
- Filtering
- Aggregations
- GroupBy Operations
- Schema Modification
- Wide Transformations
- Data Processing Pipeline

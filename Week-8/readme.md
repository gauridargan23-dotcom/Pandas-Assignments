# Week 8 - E-Commerce Order Analytics System

## Objective

Build an end-to-end e-commerce data analytics system using Python and SQL to generate, clean, validate, store, and analyze order data.

## Tasks Performed

- Generated sample customers, products, orders, and order-items data using Python
- Introduced intentional data quality issues
- Cleaned and transformed raw datasets using Pandas
- Validated customer emails and data values
- Checked referential integrity between tables
- Generated cleaned CSV files
- Generated a data quality validation report
- Created MySQL database and relational tables
- Loaded and analyzed cleaned e-commerce data using SQL
- Performed revenue, customer, product, and order analysis
- Used SQL CTEs, subqueries, and window functions
- Implemented customer segmentation and cohort analysis
- Integrated Python with MySQL for generating reports

## Technologies Used

- Python
- Pandas
- NumPy
- Faker
- MySQL
- SQL

## Outcome

Successfully implemented an end-to-end **E-Commerce Data Analytics System** covering data generation, data cleaning, validation, SQL analysis, and automated reporting.
